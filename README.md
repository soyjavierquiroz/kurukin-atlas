# Kurukin Atlas

Kurukin Atlas is Kurukin's curated internal asset retrieval system.

## Responsibilities

- ingest validated producer assets
- maintain logical assets and renditions
- catalog and provenance
- structured and semantic retrieval
- Atlas-local ranking
- contradiction handling
- scarcity
- stable asset resolution for MPT

## Architectural boundary

MBE produces quality.

Atlas stores and finds quality.

MPT uses quality.

## Core principles

- QUALITY > QUANTITY
- FILE != LOGICAL ASSET
- HORIZONTAL / VERTICAL = RENDITIONS
- VISUAL != NARRATIVE
- QUERY != ASSET EVIDENCE
- UNKNOWN != MISMATCH
- SCARCITY > FAKE MATCH
- SCARCITY != FAILURE
- SCOPE IS HARD
- NO SILENT SCOPE EXPANSION
- ATLAS RANKS ATLAS
- MPT RANKS PROVIDERS
- NO DOUBLE ANALYSIS
